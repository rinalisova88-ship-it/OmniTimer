# ⏳ OmniTimer

![Версия расширения](https://img.shields.io/badge/version-1.4-blue)
![Chrome Web Store](https://img.shields.io/badge/Chrome-Extension-2ea44f)
![Лицензия](https://img.shields.io/badge/license-MIT-green)

**OmniTimer** — это расширение для браузера Chrome, которое автоматически отслеживает время, проведённое в чатах **OmniDesk (Helpdesk)**. Помогает анализировать загруженность сотрудников, учитывать время на тикетах и контролировать распределение задач.

![Демонстрация работы расширения](screenshots/demo.png)

---

## ✨ Основные возможности

| Функция | Описание |
|---------|----------|
| **Автоопределение компании** | Таймер автоматически считывает название компании из карточки чата и запускает учёт времени |
| **Ручное создание задач** | Можно добавить свою задачу (например, «Совещание», «Обучение») и вести учёт по ней |
| **Визуальный статус в бейдже** | Иконка расширения меняет символ и цвет в зависимости от состояния |
| **Пауза / Стоп** | Полный контроль над таймером в любой момент |
| **Защита от рассинхрона** | Если вы открыли чат А, а время идёт по чату Б — появится предупреждение (≠) |
| **Heartbeat-механизм** | Таймер автоматически останавливается, если закрыть вкладку OmniDesk |
| **Статистика за смену** | Список всех компаний с накопленным временем, кликабельный |
| **Экспорт в CSV** | Отчёт можно скачать в формате Excel/CSV одним нажатием |
| **Очистка за день** | Быстрый сброс всей статистики |

## 🎨 Состояния бейджа

| Бейдж | Цвет | Когда отображается |
|-------|------|---------------------|
| `ON` | 🟢 Зелёный | Таймер активен, компания совпадает с текущим чатом |
| `\|\|` | 🔵 Синий | Таймер на паузе |
| `■` | 🔴 Красный | Таймер остановлен, нет активной задачи |
| `≠` | 🟠 Оранжевый | **Рассинхрон**: таймер тикает по другому чату, а вы смотрите другой |

## 📦 Установка

### Способ 1: Загрузка из репозитория (для разработки)

1. **Скачайте или клонируйте репозиторий:**
   ```bash
   git clone https://github.com/rinalisova88-ship-it/OmniTimer.git

2. **Откройте Chrome** и перейдите в `chrome://extensions/`
3. **Включите «Режим разработчика»** — переключатель в правом верхнем углу
4. **Нажмите кнопку «Загрузить распакованное расширение»** (Load unpacked)
5. **Выберите папку**, в которую распаковали проект

### Способ 2: Скачайте и распакуйте zip-архив и повторите пункты 2-5.
